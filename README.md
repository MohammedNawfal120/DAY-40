# Day 40 - Tailwind Grid Task

A responsive model website layout made with React and Tailwind CSS Grid, following the supplied Day 40 example.

## Run

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Check the production build

```bash
npm run build
```

## Features
- Blue header, sidebar menu, main content, three colored cards, dark footer
- Responsive CSS Grid: one column on mobile and three columns on medium+ screens
- Main content spans two of the three desktop columns
- Cards stack on small screens and form three columns on wider screens

The project is a layout demonstration, so menu items and cards are not interactive.
